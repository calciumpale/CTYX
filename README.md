# 营销工作台

营销工作台围绕社交平台获客、项目跟进、提醒及日程、合同及审批、培训提升、知识库组织销售与管理任务。界面采用 Linear 紧凑中性方向，以白灰表面、系统字体和紧凑列表呈现业务。数据由服务端保存，刷新后可继续工作。

## 已实现的业务

- 主 Agent 识别意图，调度既有领域专家；具体能力使用 AI 客户洞察、AI 策略方案、AI 商机预测、AI 合同初审、AI 销售陪练与 AI 会议纪要等名称，展示执行过程与引用。
- 项目跟进以企业通讯录展开，中心为当前项目的 AI 对话，右侧查看画像、商机评分和下一步建议；同一企业可切换项目。合同与审批共用独立入口。社交平台获客分为新建任务、筛选线索、留资对接，保留现有抖音采集、审核、聊天与留资能力。
- 优秀案例可提炼为待审核 Skill；管理者确认后发布，待审核与退回内容不进入检索。
- 培训提升中的 AI 销售陪练支持文字与双向语音、多轮对话、结束评价和历史记录。
- 知识库支持 Excel（XLSX / XLS）、PDF、DOCX、TXT、Markdown 和 CSV 导入，搭建中心支持节点配置、连接、保存、测试与发布；运行记录保留轨迹。
- 浅色与深色主题、响应式布局、中文输入法保护和减少动态效果偏好。

## 本地运行

需要 Node.js >=22.13.0。首次执行：

```sh
npm run install:ci
npm run build
```

将 drizzle/ 下尚未执行的 SQL 迁移按文件顺序应用到本地数据库。将下方文件名替换为实际生成的迁移：

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_glossy_scream.sql
npm run dev
```

打开终端打印的本地地址（默认 http://localhost:5173）。本地登录通过 /signin-with-chatgpt?return_to=/ 模拟身份；线上由 Sites 平台认证。数据库保存在忽略提交的 .wrangler/state/，不要重复执行已应用的迁移。修改数据库结构后运行 npm run db:generate。

```sh
npm run typecheck
npm run check:tokens
npm test
npm run build
```

## 数据与权限边界

首次使用初始化合成示例数据，不包含真实企业客户。商机健康度和演示模式的带练分数来自规则，不能当成经过校准的成交概率。示例成功案例用于演示 Skill 流程，不证明话术带来的因果转化提升。

每个 Sites 登录身份的数据保持隔离，工作空间内使用销售、销售管理者、管理员岗位账号登录。服务端按账号会话与项目权限逐请求鉴权，管理员默认不取得客户项目与业务审批权限。企业 SSO 与 CRM 尚未接入。

业务写入使用版本检查，过期更新返回 409，避免覆盖其他会话的修改。Skill 审核、工作流发布等操作在服务端检查权限。工作流发布和运行校验节点类型、连通性和循环；人工审核节点暂停执行，不能自动审批。

## 接入真实模型

未配置模型时，界面明确显示演示模式，并用规则生成演示答案和训练反馈。可在服务端配置兼容的模型接口：

- MODEL_API_KEY：服务端密钥。
- MODEL_BASE_URL：兼容接口的基础地址。
- MODEL_NAME：模型标识。

参考 .env.example，本地配置放在忽略提交的 .dev.vars，线上通过托管平台的服务端环境配置。不要把密钥放到浏览器、源码或 Git。实际模型连接状态以设置页为准。

## 技术结构与部署

React / TypeScript / Vinext + Cloudflare Worker + D1 / Drizzle。统一业务 API 位于 app/api/workbench/route.ts，共享契约位于 API_CONTRACT.md，核心领域规则位于 app/lib/domain.ts。

.openai/hosting.json 声明 Sites 项目、DB 与 BUCKET 绑定。通过 Sites 发布流程构建、提交源代码、打包并私有部署，线上部署应用数据库迁移。npm start 只预览构建结果，不会部署。

用户故事与设计约束见 PRODUCT.md、DESIGN.md，实现计划与验证目标见 docs/superpowers/。开发缓存、凭证和构建产物保持忽略，不上传原工作空间的面试资料。

## 已有客户资料

原有跟进文字、录音和会议资料保留为企业项目上下文，可在画像侧栏的资料中查看。录音继续由私有 R2 保存，回听重新验证项目权限。客户原话可在项目资料中补充；原独立跟进记录页面与会议工作台入口已收起。

## 双向语音带练

进入培训提升中的 AI 销售陪练，选择语音模式后开始练习。客户回复由浏览器语音合成播放，可停止或重播，并调整音色与语速；点击开始说话后申请麦克风权限，识别文本可编辑，确认发送后写入既有训练记录并用于复盘。切换场景、历史记录、文字模式或离开带练时停止语音。

本功能采用浏览器 Web Speech API，无需额外模型密钥。识别功能因浏览器、系统、权限和识别服务可用性而异；页面检测能力并显示错误，不支持时仍可文字带练。部分浏览器会把音频交由其语音服务联网识别；本工作台不保存原始音频，只保存用户确认发送的文字。客户音色来自设备可用的语音服务，语音播报不改变当前规则演示生成的性质。参考 [语音识别](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition) 与 [语音合成](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis) 文档。

## 提醒及日程

侧栏独立入口“提醒及日程”支持任务、日程和客户拜访，提供周、月、列表视图与待安排清单。记录持久化到 D1，时间按 Asia/Shanghai 解释；业务成员管理自己的安排，管理者可读取团队安排。AI 日程助手复用已配置模型，只生成待核对草稿，保存后才写入日程。手动日历不依赖模型配置，不包含外部日历或邀请同步。

项目截止提醒与日历同页展示，阈值沿用业务规则；管理者可从这里查看待审批与销售日报。旧的概览链接转到项目跟进，普通会议链接转到提醒及日程；腾讯会议嵌入专用链接继续可用。

## Excel 知识资料

上传 Excel 后在浏览器内解析，按工作簿顺序保留各工作表、原行号、单元格地址及显示值，随后沿用普通或父子切块、BM25、向量和混合检索。原 Excel 文件不会上传到服务端；用户确认导入后保存提取文字及原文件名。隐藏工作表一并解析并标识，合并范围保留，空表会提示。

支持 XLSX 与 Excel 97–2003 XLS（OLE 工作簿）。上限为文件 10 MB、正文 80,000 字符、50 个工作表、每表 20,000 行与总计 100,000 个非空单元格；XLSX 解压总量不超过 32 MB、单条不超过 16 MB。损坏、加密或超限时整体拒绝，不导入部分前缀。

公式不重新计算：保留公式及文件保存时的结果，无缓存结果明确标出。图片、图表、批注、宏与嵌入对象不作正文解析，外部链接不会被访问。解析运行于独立浏览器 Worker，45 秒超时停止。使用固定版本 [SheetJS CE 0.20.3 官方发行包](https://docs.sheetjs.com/docs/getting-started/installation/frameworks/)，按需加载，不在页面运行时连接第三方 CDN。

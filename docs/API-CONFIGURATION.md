# 大模型 API 配置

入口：侧栏「设置」→「API 配置」。本次只提供大模型连接，语音服务继续使用现有独立配置。

填写提供方的 OpenAI 兼容 Chat Completions Base URL（一般包含 `/v1`）、模型标识和 API Key。点击「测试连接」会向该地址发起一次简短测试请求，不发送客户资料；该调用可能按服务商规则计费。保存并启用后，工作台专家任务和工作流使用新配置，无需重新部署网页。

配置归属当前平台登录账号，销售/管理者体验视角共用此账号配置。API Key 仅从输入框发送到本应用服务端；保存后不回显，不写浏览器存储，也不写入业务工作空间 JSON。编辑时留空会保留已保存密钥。连接测试成功只代表本次请求成功；保存本身不代表已通过测试。

当前带练客户对话和复盘仍采用规则演示，接入模型不会自动改变该模块。语音 ASR/TTS 网关也不会由此替换。

## 部署维护

- 新表 `workbench_api_connections` 使用平台用户 ID 隔离记录；迁移为 `drizzle/0001_motionless_tana_nile.sql`。
- `CONFIG_ENCRYPTION_KEY` 是服务端的 64 位十六进制密钥，用 AES-GCM 加密数据库中的 API Key，并绑定账号和连接类型。
- 本地值放在忽略提交的 `.dev.vars`，线上值由 Sites secret 管理。保持加密密钥稳定；更换前须迁移已保存的密文。
- 旧的 `MODEL_BASE_URL`、`MODEL_NAME`、`MODEL_API_KEY` 环境配置继续作为默认值；账号配置优先。关闭账号配置后不会继续调用被覆盖的环境默认值。
- 生产 API 地址必须使用 HTTPS，禁止在 URL 中携带凭据或查询参数，不跟随重定向转发密钥。仅本机 HTTP 调试页可连接回环 HTTP 模型服务。

测试和业务调用遇到提供方错误时返回清晰提示，不把提供方原始响应体或密钥输出到页面和日志。

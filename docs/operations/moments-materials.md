# 朋友圈草稿定时生成

计划属于创建它的工作台成员。定时器按北京时间判断是否到期，每小时检查一次。同一计划每天最多创建一个自动草稿。启用计划前需要连接文字模型；开启配图时还需可用的素材服务。停用或删除计划会停止新的定时生成，已有草稿保留。

## 无人值守调用

仅在所有者私有的 Sites 站点上使用。通过 Sites 工具读取此站点的服务访问凭据，按其服务访问说明请求 `POST /api/moments-materials/maintenance`。使用 `Content-Type: application/json`、请求体 `{}` 和 Sites 服务授权。请求中不发送浏览器 Cookie、访客身份或客户参数。凭据不写入代码、文档、任务说明或日志。

每次调用只处理有限批次。核对响应中的 `queued`、`processed`、`statuses`、`errors` 和 `hasMore`。仍有可处理批次时，最多续调四次。收到 `image_pending` 时可以短暂等待后检查一次，同一个配图任务只提交一次。没有到期计划时不生成内容，也无需通知。

生成结果保存在「AI营销素材 → AI 朋友圈」。用户在工作台检查草稿、复制文案并下载图片。

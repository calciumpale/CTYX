# 录音转写增强

用户要求：方言识别、热词表纠偏和讲话人区分。保留实时双工陪练的收音、插话和自动提交逻辑。

## 设计

- 在设置中提供账号隔离的语音识别设置与热词表：标准词、明确误识别写法、启用开关；支持方言提示、自动/指定讲话人数。
- 上传录音仍先保存原始文件。另行异步排队识别，可查看进度、失败重试，不能因模型失败丢失录音。
- 自部署网关增加有签名认证的 HTTP 转写任务接口，磁盘持久化任务，单任务 CPU 推理；后台处理长录音，不阻塞实时 WebSocket。
- 本机使用 sherpa-onnx 1.13.8 已有绑定：FunASR-Nano int8 识别，Pyannote segmentation 与 3D-Speaker embedding 分人。原音频不发送给外部模型服务。模型下载只访问官方发布源。
- 热词既进入模型识别上下文，也用于用户明确配置的误识别写法纠偏；保留原始文字、改写记录和时间戳。说话人编号只是音色聚类，不冒充身份识别。
- 转写结果按讲话人和时间展示，保存到关联项目，进入既有客户洞察与话术提炼链路。长结果独立持久化，避免无限扩大工作空间 JSON。
- 界面沿用 Claude 视觉系统，保持中文阅读与手机布局；不使用装饰性左侧色条。

## 实施与验证

1. 实现设置/任务类型、D1 存储、鉴权路由、录音任务接入和项目落库。
2. 实现热词管理与转写结果组件，自动轮询在途任务、保留错误重试入口。
3. 实现网关后台任务、音频解码、方言识别、讲话人分段与纠偏；下载并实际加载模型。
4. 有意义的测试覆盖权限隔离、热词冲突/纠偏、任务幂等、失败保留原录音、分人及真实模型片段。
5. 用所附约80分钟讲座的短片段实际识别；长音频按内存/时长界限处理并记录真实耗时，不把普通话测试当作全部方言准确率证明。
6. TypeScript / Python 测试、构建、桌面手机视觉检查；沿原站点权限发布网页，本机服务说明真实可用状态。

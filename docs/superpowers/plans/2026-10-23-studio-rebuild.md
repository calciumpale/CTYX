# 搭建中心重构实施计划

**目标：** 将现有混合式工作流展示页重构为可创建、编辑、调试和发布的独立搭建工作区。用户此前指定 Coze 式搭建能力与 Open Claude UI 样式。

**范围：** 应用列表、Agent 配置、工作流画布、类型化节点配置、当前草稿调试、节点执行轨迹、人工确认续跑、独立发布快照。五位领域专家保持原定义。原有商机、录音、知识、Skill 审核、带练和模型配置保留。

**结构：** BuilderStudio 负责列表/编辑/使用状态与未保存保护；WorkflowCanvas 与 workflow-graph 负责图交互和布局；domain 负责校验、实际执行和版本快照。沿用 Workbench API 与账号隔离的 D1 JSON 存储，不引入新的依赖或数据库迁移。

## 任务

- [x] 发布与调试契约：Workflow 增加 kind、可选 published 快照；条件边仅用于意图节点；TraceStep 对应 nodeId/input/output；Run 区分完成、暂停、失败和拒绝。
- [x] 执行闭环：直接调试当前草稿；草稿保存不覆盖线上版本；意图真实选分支、知识选择实际生效、输出按图依赖汇总；人工确认在原角色授权范围恢复；失败保留可见轨迹。
- [x] 画布：真实输入/输出端口连线、拖动、平移缩放、适应、保留连接的自动整理、键盘操作与删除连线；图操作回归测试。
- [x] 应用工作区：区分 Agent 与工作流；节点只显示实际生效字段；调试与画布同屏；未保存修改拦截内部切换、导航、角色切换和任务入口。
- [x] 兼容：旧工作流无 kind/published 时仍可读取；销售只见线上版本，管理者可编辑草稿；现有暂停旧记录不伪装成可恢复。
- [x] 验证：全套测试、类型与 token 检查，实际 Worker 调试/保存/发布/旧版隔离/审批续跑，浏览器桌面画布及窄屏布局，独立审查通过。

## 验证结果

完整测试 100/100；TypeScript、改动文件 ESLint、CDS token 检查（20 文件、0 错误）、diff 检查通过。一次 Impeccable 检测无问题，独立审查最终结论为 ship。

浏览器完成空白工作流创建、真实端口连线、保留连线的自动整理、未保存草稿测试、保存与发布、拖动与撤销、离开保护。独立 Agent 配置、1440px 桌面、390px 窄屏及深色主题已检查。销售发起已发布流程后暂停，管理者刷新后从待确认列表恢复原运行，下游执行且上游无重复。

部署沿用原 owner-private Site，无新依赖、数据库迁移或权限调整。验收仅使用自有合成记录，交付前按精确 ID 清理。

## 验收重点

1. 连接端口真的修改图，自动整理不改变任何连接。
2. 编辑未保存提示词后试运行，结果来自当前内容；保存记录仍未被覆写。
3. 发布后继续编辑并保存，销售仍能运行原发布版，重新发布后才切新版本。
4. 条件路由只调用选中的分支；候选和退回 Skill 无法进入知识检索。
5. 人工确认后从原暂停图继续，不重复上游，也不扩大原销售的数据范围。
6. 失败/暂停/跳过状态与节点轨迹一致；页面不把规则演示或旧测试显示为当前真实模型成功。
7. 放弃更改需要明确选择；取消离开保留当前图。无装饰性左侧彩条。

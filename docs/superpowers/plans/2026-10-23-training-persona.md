# 客户画像确认与自然带练

**目标**：用户先设置并确认模拟客户，再进入文字或语音带练。客户根据画像和对话自然回应。

**实现决定**：沿用现有 React / TypeScript / D1、Open Claude UI 与模型 API 配置。画像作为每次训练的不可变快照存储，不修改商机资料。新训练必须通过服务端确认校验。

## 范围

- 画像维度：称呼、行业、角色、需求、预算、时间安排、决策方式、沟通风格、核心顾虑、难度；按三个现有场景提供可修改的模拟默认值。
- 配置 → 预览画像 → 确认开始；返回修改后重新预览。确认前不创建训练、不调用模型、不启用麦克风。
- 训练中可查看确认的画像；旧记录缺少画像时正常展示并明确说明。
- 开场及后续回应调用已配置的大模型，传入画像与有界完整历史。未配置时明确使用本地规则演示；API 失败保留当前对话并提示重试。
- 客户保持角色，口语短句，一次一个主要关切；先回答销售的问题，再决定是否追问，不机械提问、不评价销售表现、不重复已回答信息。
- 保留全双工语音、自动提交、语音轮次去重、权限、版本冲突、20 轮上限和规则复盘。

## 重点检查

画像中的自由文本不能提升为系统指令。模型失败不可保存半轮对话；重复语音轮次不重复调用模型。已确认画像不能随新一轮表单变化。多轮回复不能把销售发言与客户发言角色颠倒。手机布局无页面横向溢出，文字/语音均经过同一确认入口。

# 界面文案与运行记录整理

**目标**：移除界面上反复出现的体验、示例与演示标记；让运行记录优先呈现任务结果，执行细节按需查看。

**实现**：保留 Open Claude UI、现有业务流程、模型状态和服务端记录。文案只调整展示，不改写客户、历史结果或知识原文。账户、数据与集成现状统一放在设置中的折叠说明，不制造已接入企业系统的事实。

- 侧栏、账号、首页、商机、训练与搭建入口清理重复前后缀，模型状态用简明准确的名称。
- 运行记录迁移到独立组件：桌面端紧凑记录索引与结果阅读区；手机端列表进入详情，并提供返回入口。
- 搜索与状态、任务来源筛选；结果默认展开，执行过程与引用分开；技术元数据折叠，复制与提炼为辅助操作。
- 保留候选 Skill 的证据边界、权限和人工审核流程。不得使用装饰性左侧彩色竖条。

**验证**：状态与筛选逻辑测试、完整测试、类型与 token 检查；一次桌面、手机和浅深主题验收；独立审查。保持原站点访问范围，使用原项目发布。

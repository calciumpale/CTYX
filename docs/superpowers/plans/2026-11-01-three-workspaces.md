# 三类工作台 Implementation Plan

**Goal:** 按已批准方案交付三类工作台、管理员知识运营和三个真实应用账号。

**Architecture:** 复用现有Sites私有身份、D1/R2和领域功能；附加账号会话与服务端能力授权，不以隐藏菜单替代权限。前台按岗位组织入口，管理员规则和业务设置实际落库。

**Tech Stack:** React / TypeScript / Vinext / Cloudflare D1 / Web Crypto。

**Spec:** docs/superpowers/specs/2026-11-01-three-workspaces-design.md

## Tasks

- [x] 账号与会话：先测首次初始化、密码散列、错误登录、过期退出、跨Sites隔离与伪造header；实现auth store、路由、middleware和迁移。
- [x] 授权与规则：先测三角色action/API边界、admin数据脱敏、业务阈值CAS；实现服务端策略、审批账号区分和业务规则存储。
- [x] 登录与首页：实现登录/登出、今日与团队首页，全部入口连接真实已有流程，客户端取消旧账号请求。
- [x] 工作台整合：角色导航、项目新建/跟进入口、知识与话术运营、人员规则及服务界面；手机列表与电脑看板相衔接。
- [x] 集成验收：三账号实际HTTP登录和正向操作、越权403、桌面手机一轮检查，最多一轮修复；类型、必要单测、构建、独立审查。
- [ ] 发布：源助手提交打包，保留原私有分享及定时任务，部署后返回网址与三个账号密码。

## Review Focus

保护原Sites身份与配置；middleware确实在生产和本地运行；账号切换期间异步响应不串数据；审批申请人和审批人共享工作空间但不能被误当成同一人；管理员不读取销售资料正文且不能绕过管理者话术审核。

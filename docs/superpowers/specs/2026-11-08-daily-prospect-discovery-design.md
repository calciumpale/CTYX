# 每日竞品与线索发现方案

## 目标

在线索筛选中为每个获客任务设置每日发现时间，默认北京时间 09:00，可修改、启停。结果显示本轮新增账号、评论和线索，历史审核与已选账号保留。

## 方案与采集范围

推荐复用已登录的本机助手：服务端持久化计划和每日轮次，助手轮询时领取到期任务，关闭网页仍可运行；离线恢复只补最近一轮。云端定时器只能创建任务，无法替代本机浏览器采集，因此本轮不增加独立云端执行器。

范围 A：每日刷新竞品发现结果，同时自动采集已选竞品；新发现账号由用户选择是否纳入。范围 B：新发现账号也自动纳入本轮采集。用户已明确选择 B，按 B 实现；保留用户之后主动取消的历史账号选择。

## 行为

- 每个任务设置每日开关和时间；界面显示下次时间、本轮状态及最近结果。
- 同一任务同一个计划日期只创建一个轮次；并发轮询、重启、重复上报不会重复采集。暂停任务或关闭计划后不再产生新轮次。
- 发现结果按账号合并，不清空已选账号。选择持久化，不依赖当前网页是否打开。
- 按关键词、账号和作品拆分执行，优先处理会话同步及回复，避免每日采集长时间占住助手。
- 原始评论 ID 优先；缺少原始 ID 时使用稳定指纹，兼容旧相对时间指纹，避免“昨天/三天前”变化形成重复线索。
- 每轮统计新增账号、评论和线索，提供本轮新增筛选；已审核、已发送状态不因重新发现被覆盖。
- 解除现有任务终身 300 条评论上限，改为每批采集预算和列表分页，确保后续日期仍能产生新增结果。

## 验收

覆盖计划时间及跨日、离线补一轮、幂等、暂停/重启、租户和成员隔离、候选合并与选择保留、跨天评论去重、本轮新增统计，以及消息回复优先级。沿用当前紧凑布局与统一控件高度。

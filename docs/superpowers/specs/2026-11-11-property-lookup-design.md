# 知识库房源逐条筛选

用户要求商铺问答读取已解析的空置、在租房源，按面积、业态、位置组合匹配，返回一条或多条对应记录。

现有 hybrid top-k 文本片段不能枚举完整房源，还会将不同记录的数字视为冲突。本次选用独立的原文行筛选通道：读取授权知识库当前解析版本，核验完整性，按 Excel 列地址、Markdown 表头或 CSV/TSV 列建立记录。避免增加依赖或要求现有资料重传。

部门和租户范围来自服务端账号；模型只辅助抽取用户原话中的条件，不能更改权限、放宽面积或虚构房源。面积区间、边界、状态和精确行匹配由代码完成。空置问题只返回明确空置记录，在租同理。位置、业态等条件同时生效；未知或冲突字段不视为满足条件。未注明面积单位时展示原值并提醒核对。

结果逐条保留原始字段、文件、工作表、行号和文件更新时间，标记“知识库房源筛选”。不再次让模型改写筛选事实。多条按真实字数预算分页，连续追问可收窄条件或继续翻页。超出容量或原文不完整时明确说明覆盖范围，不能把读取失败当作没有房源。

验证覆盖真实表头、数值边界、否定、OR、未知条件、缺字段、来源状态冲突、权限隔离、旧分块完整性、翻页，以及真实 Worker 的上传—提问—追问链路。部署沿用现有 owner-private Site。

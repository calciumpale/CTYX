# AI营销素材创作与设计

「创作与设计」在现有素材页里把灵感、成稿、画布和模板连到同一个项目。营销海报、网页、App、小程序都是可编辑的画板类型。既有图文生成、AI 朋友圈和数字人仍从素材页进入。

- 成稿采用创作资料与稿件分栏。按产品事实、受众、平台和风格生成可编辑标题、文案、脚本和分镜，按需请求生成封面、下载稿件或加入日程。
- 设计采用点阵工作面、可缩放的并排画板和图层属性栏。用户可以应用模板、创建视觉方向、选择画板或图层后提出修改，并检查结果。
- 项目按工作空间及成员保存。每次保存保留独立版本。两个版本可以并排预览，把旧版载入草稿后可另存为当前版本。
- 设计市场包含工作台模板和工作空间共享模板。发布只复制经确认的画板及模板说明。包含账号私有图片的画板须移除图片后才能共享。
- 交付包含当前画板 PNG 和可离线打开的 HTML、可运行的 React、Vue、uni-app 源码包。画布由受控图层描述绘制。文字和图像分别使用工作台已有的模型和素材服务。

用现有浅深主题、中性控件、完整边框及清晰的选中态。窄屏允许画布独立滚动。生成与保存失败保留当前草稿，版本冲突可打开最新保存版。所有生成服务通过原有服务连接配置，发布验证使用模拟数据。

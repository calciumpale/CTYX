## 页面验收

## 交付与运行条件

- 主入口为工作台的“抖音获客”，销售和管理者仅能操作自己的任务，管理员不读取获客正文。
- 默认人工审核；创建任务时可选择模型阈值自动发送。规则初筛不会自动发信。
- 本机助手需要 Node.js 22.13+、专用 Chromium、设备配对及用户亲自扫码。私有 Sites 另需管理员提供的 `sitesToken`，该凭证不写入前端、下载包或源代码。
- `/downloads/douyin-bridge.zip` 由 `npm run prebuild` 重新生成，仅包含 7 个白名单文件；无 node_modules、浏览器 profile、配置或执行日志。
- 构建、源代码推送和部署由 Sites 发布流程执行，保留现有访问范围；发布是否完成以原生部署返回状态为准。

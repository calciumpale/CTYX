# 抖音收信与人工接管修复

## 已确认原因

- 隔离浏览器复现截图中的换号报错：读后临时缺少本人控件被折叠成 ACCOUNT_CHANGED，读取结果被丢弃；已有身份提示也被清除，随后反复恢复。
- 本机日志快照 69 次读取有 39 次失败，其中 36 次在读前或读后本人校验处失败。失败仍推进 last_read_at，下一轮又等 60 秒。
- 现场另确认旧私站访问凭证返回 403；同范围刷新后，真实设备心跳返回成功。凭证仅保存在本机权限 0600 的配置文件，不进入源码或发布包。

## 实现

- 临时缺证据、明确换号、退出登录、安全验证分开处理；暂缺进入有界恢复，真实账号边界继续停止任务。
- 读取在同一身份标签页刷新 canonical 本人证据，不因暂缺信息跳到 SELF / 搜索重新发现。读前与读后均验证当前会话身份，旧标签页残留不能授权新账号的聊天内容。
- 保留严格出站身份、收件人、快照、租约、持久日志与未知发送防重发校验。
- 常规自动收信间隔 30 秒，失败或不可靠读取间隔 15 秒；按最后尝试公平轮询，人工同步仍保留 8 秒防抖。以上为调度间隔，实际延迟还包括队列与平台加载时间。
- 收信先入队，已有来信每轮最多获得一个决策机会，避免多会话持续收信挤占回复；拒绝联系优先处理。
- 转人工按客户要求、价格/合同/投诉等业务问题、模型/检索故障及资料不足给出简短原因与下一步；不展示原始模型理由。同步失败不覆盖原有商务或人工接管原因。
- 界面显示实际可靠的抖音同步时间，区分失败、停滞及尚未可靠同步，保留只读会话的接管原因。

## 验证

- 最终完整测试：985 通过，0 失败，0 跳过；类型检查通过。
- 账号边界与会话浏览器定向回归：62 通过；调度与存储定向回归：55 通过。
- UI 隔离验证覆盖手机/桌面、只读/旧记录原因、done+error、实际同步时间、缺失时间、中文输入法、快捷键、草稿与禁用状态；相关回归已写回测试。
- 独立审查发现并关闭持续收信饿死决策、旧身份 DOM 跨账号混用两项问题。
- 所有软件浏览器测试使用合成数据和隔离页面，没有向真实客户发送测试消息。

## 普通账号与官方接口

普通账号继续使用已配对本机通道。官方企业私信事件推送需要获批企业号及对应权限，不能假设普通账号可直接切换。官方说明：https://open.douyin.com/platform/resource/docs/ability/enterprise-account-open-ability/message-solution/
